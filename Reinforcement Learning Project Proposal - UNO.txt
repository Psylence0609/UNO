Proposed Starting Point


The project will use the RLCard library as the foundation, which provides a standardized Uno environment with game rules already implemented. RLCard offers:
* Pre-built Uno game engine with state representation
* Standard interfaces for training RL agents
* Baseline rule-based agents for comparison


Resources Needed:
* Access to computational resources (HPRC for training, etc)
Project Plan


Uno is inherently sequential as each player's action affects the game state, and decisions must consider both current hand composition and opponent behavior over multiple turns. The game continues until one player exhausts their hand.
State Representation:
RLCard's Uno environment provides a comprehensive state representation including:
* Player's hand: Card composition with color and number/action properties
* Discard pile: Top card visible to all players
* Opponent information: Number of cards remaining in each opponent's hand
* Game state variables: Current direction (clockwise/counterclockwise), active color after wild cards, turn order
* Action legality: Valid moves available to the current player
Action Space:
* Play any valid card matching color, number, or wild cards
* Draw from deck when no valid plays exist
* Color selection when playing wild cards
Transition Function:
* Deterministic given player actions
* Stochastic due to random card draws from deck
* State changes include card removal from hand, discard pile updates, turn order modifications (Skip, Reverse), and forced draws (Draw Two, Draw Four)
Reward Function
1. Basic Approach:
Standard sparse rewards (+1 win, -1 loss, 0 during gameplay) cause severe training difficulties due to delayed feedback in games that can exceed 200 rounds.
2. Advanced MCTS-Based Reward Reshaping :
A 2024 research paper demonstrated superior results using Monte Carlo Tree Search for reward reshaping:
   1. Terminal rewards: +1 for winning, -1 for losing
   2. Intermediate MCTS rewards
This approach yielded 4-16% higher win rates compared to standard DDQN by providing meaningful feedback during gameplay rather than only at episode termination.


Implementation Strategy / RL Algorithm
1. Simplest First Result:
Train a Deep Q-Network (DQN) agent that can:
   * Learn valid move selection
   * Beat the random baseline agent consistently (>60% win rate)
   * Demonstrate basic strategic card selection (e.g., playing high-value cards early)
2. Deep Monte Carlo:
DMC combines traditional Monte Carlo methods with deep neural networks, making it particularly well-suited for Uno's large action-state space and episodic nature. The algorithm addresses key limitations of DQN, including overestimation bias and slow convergence with sparse rewards, while offering efficient parallelization for scalable training.
Training data is generated through self-play simulation. The agent plays millions of games against itself or other agents within the RLCard environment. Hence, no external dataset is needed and  the environment generates all training data automatically.


Baseline Comparisons
We will first use a Random Agent to compare with our simplest model. Hence the comparisons will be as follows:
   1. Random agent (plays any valid move) vs DQN + Basic Reward Function
   2. DMC + MCTS vs  DQN + Basic Reward Function
   3. Comparisons with Rule-based agent (RLCard's built-in heuristic agent)


Stretch Goals
   1. Opponent Modeling: Enhance state representation to track opponent playing patterns
   2. Multi-agent Training/Testing: Train agents against each other using self-play for emergent strategies. We can also let different models play against each other and test their performance.
   3. Strategic Depth: Implement card counting and probability estimation for optimal Wild/Draw Four timing.
   4. Transfer Learning: Test trained agent's performance against human players or different rule variations.


Evaluation Metrics
   * Win rate against different opponent types
   * Average game length
   * Strategic behavior analysis (card retention patterns, wild card usage timing)
   * Training convergence speed and stability
